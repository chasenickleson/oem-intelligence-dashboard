# OEM Intelligence Dashboard

Live site: `https://chasenickleson.github.io/oem-intelligence-dashboard/`

## Automatic monthly refresh
The scheduled workflow refreshes the Newsroom, evidence-based market indicator tiles, composite score and label, driver scores, leadership topics, executive brief, outlook scenarios, economics commentary, and OEM opportunity areas. Existing source-library links remain curated.

## Methodology
This no-key version uses public Google News RSS headline metadata and transparent keyword/rules-based scoring. Monthly score movement is capped at five points to reduce headline-driven volatility. If a segment retrieval fails, the last successful segment data remains in place. This is directional market intelligence, not a surveyed index, and should be reviewed before external distribution.
